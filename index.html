Function reference: metrics(y_true, y_pred)

Computes regression accuracy metrics for observed versus predicted net electrical power output.

Inputs: y_true and y_pred, aligned array-like numerical values in MW.

Returns: a dictionary containing MAE_MW, RMSE_MW (both MW), and R2 (dimensionless).

def metrics(y_true, y_pred):
    """Calculate prediction accuracy metrics for power-output regression.

    Compare observed and predicted net electrical power output using three
    complementary metrics. MAE and RMSE are expressed in megawatts (MW),
    while R² is dimensionless. Lower MAE/RMSE and higher R² indicate better
    agreement between predictions and observations.

    Args:
        y_true (array-like): Observed net electrical power output (PE), in MW.
        y_pred (array-like): Predicted PE values, in MW, in the same order
            and with the same length as ``y_true``.

    Returns:
        dict[str, float]: A dictionary containing:
            - ``MAE_MW``: Mean absolute prediction error, in MW.
            - ``RMSE_MW``: Root mean squared error, in MW; penalises larger
              errors more heavily than MAE.
            - ``R2``: Coefficient of determination (unitless).

    Notes:
        This helper is used for model assessment on held-out observations
        and within temperature-group diagnostics. It does not fit a model.
    """

4. Holdout design and baseline models

Create a 20% test set **once** on Sheet1. All tuning and selection use the remaining 80%. The untouched test set is evaluated only after selecting a model. A mean predictor is a sanity-check baseline, and ordinary least squares is the primary engineering baseline.

    """Calculate prediction accuracy metrics for power-output regression.

    Compare observed and predicted net electrical power output using three
    complementary metrics. MAE and RMSE are expressed in megawatts (MW),
    while R² is dimensionless. Lower MAE/RMSE and higher R² indicate better
    agreement between predictions and observations.

    Args:
        y_true (array-like): Observed net electrical power output (PE), in MW.
        y_pred (array-like): Predicted PE values, in MW, in the same order
            and with the same length as ``y_true``.

    Returns:
        dict[str, float]: A dictionary containing:
            - ``MAE_MW``: Mean absolute prediction error, in MW.
            - ``RMSE_MW``: Root mean squared error, in MW; penalises larger
              errors more heavily than MAE.
            - ``R2``: Coefficient of determination (unitless).

    Notes:
        This helper is used for model assessment on held-out observations

    """

7. Five repetitions of two-fold validation (5×2)

The supplied sheets are five shuffled orderings of **the same observations**. For each sheet, train on the first half and evaluate on the second; then swap halves. This produces ten paired test measurements for linear regression and the selected approach. **Important:** Model selection above already used Sheet1; therefore this is a repeated robustness comparison, *not* a completely independent post-selection confirmation. For a formal unbiased comparison, pre-specify models and settings before running this protocol, or use nested selection.

View notebook source code
from sklearn.base import clone
fold_rows=[]
for repeat,(sheet_name,frame) in enumerate(sheets.items(),start=1):
    n=len(frame);half=n//2
    for fold,(train_ids,test_ids) in enumerate([(np.arange(half),np.arange(half,n)),(np.arange(half,n),np.arange(half))],start=1):
        xtr=frame.iloc[train_ids][FEATURES]; ytr=frame.iloc[train_ids][TARGET]
        xte=frame.iloc[test_ids][FEATURES]; yte=frame.iloc[test_ids][TARGET]
        for name,est in [('Linear regression',LinearRegression()),(selected_name,clone(selected_model))]:
            start=time.perf_counter();est.fit(xtr,ytr);fit_seconds=time.perf_counter()-start
            prediction=est.predict(xte)
            fold_rows.append({'repeat':repeat,'fold':fold,'model':name,**metrics(yte,prediction),'fit_seconds':fit_seconds})
fold_results=pd.DataFrame(fold_rows)

8. Sensitivity and engineering interpretation

Permutation importance measures how much test error rises when one variable is shuffled. Correlated inputs can share importance, so this is not a causal effect. Partial dependence shows the model response when a feature changes while averaging over other observed features; unrealistic feature combinations are a limitation.

Check performance by temperature quartile and bootstrap the **fixed** test predictions to estimate uncertainty in holdout RMSE. Bootstrap intervals describe test-sample variation conditional on this fitted model, not uncertainty from training or temporal drift.
